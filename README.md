# Gesture Meme Cam – weboldal

Ez a verzió teljesen böngészőben fut: Python, OpenCV és helyi szerver nélkül.

## Használat

A weboldalt HTTPS-en kell publikálni (vagy localhoston futtatni), mert a böngésző kamerát csak biztonságos környezetben engedélyez.

Feltöltési lehetőségek: GitHub Pages, Netlify, Vercel vagy bármilyen statikus tárhely.

A MediaPipe modellek CDN-ről töltődnek be, a kamera feldolgozása a böngészőben történik.
